# imchic.github.io

GitHub 사용자 페이지용 저장소입니다.

이 저장소를 GitHub의 공개 저장소 `imchic.github.io` 로 생성한 뒤 `main` 브랜치를 푸시하면 아래 주소가 열려야 합니다.

- https://imchic.github.io/
- https://imchic.github.io/app-ads.txt

app-ads.txt 내용:

```txt
google.com, pub-1570138379392319, DIRECT, f08c47fec0942fa0
```

적용 후 해야 할 일:

1. GitHub 저장소 이름을 정확히 `imchic.github.io` 로 생성합니다.
2. 이 폴더 내용을 새 저장소에 푸시합니다.
3. GitHub Pages가 사용자 페이지로 공개되는지 확인합니다.
4. 브라우저에서 https://imchic.github.io/app-ads.txt 가 열리는지 확인합니다.
5. Play Console 개발자 웹사이트 URL을 https://imchic.github.io/ 로 설정합니다.
6. AdMob에서 업데이트 확인을 실행합니다.
